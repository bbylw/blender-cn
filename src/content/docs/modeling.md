## 从物体类型说起

在 3D 视口中按 `Shift + A` 添加物体。Blender 的“物体”分为若干**数据类型**，建模阶段常用：

| 类型 | 特点与用途 |
| --- | --- |
| **网格（Mesh）** | 由顶点/边/面构成，最通用的建模对象，几乎所有多边形建模都在网格上进行 |
| **曲线（Curve）** | 贝塞尔曲线、NURBS 与路径；适合管线、文字路径、沿曲线挤出等 |
| **曲面（Surface）** | NURBS 曲面，偏向工业设计与光滑流线造型 |
| **融球（Metaball）** | 相互“融合”的球体，适合流体状有机造型 |
| **文本（Text）** | 可直接编辑的 3D 文字 |
| **体积（Volume）** | 体素化的体积数据（如 OpenVDB 导入） |

## 建模核心流程：物体模式 ↔ 编辑模式

多数建模工作在网格上进行：`Tab` 进入**编辑模式**，在**顶点 / 边 / 面**三种子对象之间切换，逐级雕刻出形状。

### 编辑模式下的关键工具

| 快捷键 / 工具 | 作用 |
| --- | --- |
| `1 / 2 / 3` | 在顶点 / 边 / 面三种选择模式间切换（按住 `Shift` 可加选） |
| `E`（挤出） | 最常用的造型工具：把面/边/顶点沿法向拉出新的几何 |
| `I`（内插面） | 在面上插入一圈新面 |
| `Ctrl + R`（环切） | 添加一圈环形边，用于控制细分密度 |
| `Ctrl + B`（倒角） | 为边/角生成圆滑过渡 |
| `K`（切刀） | 自由切割加线 |
| `M`（合并） | 按距离或到游标合并顶点 |
| `F` | 填充：连接选中顶点/边生成面 |
| `Alt + 单击` | 环选整圈边/面（配合 `Shift` 加选多条） |

> 提示：挤出的核心是 **E + X/Y/Z + 数字**——沿指定轴精确挤出。

### 比例编辑（Proportional Editing）

按 `O` 开启**比例编辑**，拖动顶点时会影响周围一圈顶点，并可通过滚轮调整影响半径。这是制作平滑起伏、山丘、有机形态最常用的技巧之一。

## 修改器：非破坏性建模的灵魂

修改器在不直接改动原始几何的前提下，把一系列操作叠加到物体上，并且**随时可调、可叠加、可删除**。常用修改器：

| 修改器 | 用途 |
| --- | --- |
| **细分表面（Subdivision Surface）** | 平滑细化网格；结合 `Ctrl + 2` 预览级别使用 |
| **镜像（Mirror）** | 沿轴对称复制，做对称模型（人物、车辆）必备 |
| **实体化（Solidify）** | 给薄片加厚度 |
| **倒角（Bevel）** | 非破坏性的倒角 |
| **阵列（Array）** | 沿轴或曲线复制一排/一圈 |
| **布尔（Boolean）** | 与另一物体做交集/并集/差集运算 |
| **表面细分 → 多精度（Multires）** | 为雕刻提供多层细分，见[雕刻](/docs/sculpt-paint) |
| **几何节点（Geometry Nodes）** | 用节点程序化生成与修改几何，属于“特殊修改器” |

修改器列表中勾选 **实时**（视口）与**渲染** 两个开关控制显示范围；确认造型后也可以“应用（Apply）”把效果写入网格。

## 主流建模工作流

- **多边形建模（Poly Modeling）**：从立方体/圆柱等基本体出发，用挤出、环切、倒角搭出硬表面造型（工业产品、场景道具）；
- **盒子建模（Box Modeling）**：先搭大形再细分的角色建模思路；
- **程序化建模**：用几何节点或修改器链生成重复结构（建筑群、管线、自然散布），改参数即改全局；
- **曲线建模**：曲线挤出/倒角成管状物（绳索、边框），适合与路径动画配合；
- **雕刻收尾**：高模细节交给雕刻工具（见下页），再烘焙法线贴图到低模。

## 建模中常用的辅助

- **父级与实例（Instance）**：相同物体共享一份网格数据，改一个全更新；
- **集合（Collection）**：把物体组织进集合，便于管理大场景（见[资产与数据系统](/docs/assets-files)）；
- **吸附（Snapping）**：按 `Shift + Tab` 开启，顶点/边/面对齐建模非常实用；
- **游标（3D Cursor）**：按 `Shift + 右键` 定位，是所有“从哪添加/旋转中心在哪”的锚点。
