## 关键帧：动画的地基

动画的本质是“让属性随时间变化”。在 Blender 中，把某个属性（位置、旋转、缩放、强度、材质参数……）在某一帧的值保存下来，就叫**插入关键帧**：

- 把时间线指针移到某帧 → 变换物体 → 按 `I` 选择要记录的属性（或 `Alt + I` 删除）→ 移到下一帧再改再按 `I`；
- 按 `Alt + A` 播放，两个关键帧之间的过渡由 Blender **自动插值**完成；
- 切换至 **Animation 工作区**可以看到时间线、摄影表与曲线编辑器。

## 动画工作区与核心编辑器

| 编辑器 | 什么时候用 |
| --- | --- |
| **时间线（Timeline）** | 播放控制、拖关键帧、设首尾帧 |
| **摄影表（Dope Sheet）** | 总览全部关键帧，批量移动/复制/缩放 |
| **曲线编辑器（Graph Editor）** | 精细调节每一轨道的曲线形状与缓动（Easing），做出“快慢节奏” |
| **NLA 编辑器** | 把整段动画当作片段拼接、循环、分层（动作融合） |

动画曲线两端的**手柄**决定了物体是“匀速、加速还是弹跳”。想做出有生命感的动画，多在曲线编辑器里调整 **缓入缓出（Ease In/Out）** 与曲线切线。

## 让东西动起来的三板斧

1. **关键帧 + 曲线**：最直接，适合相机运镜、道具动画；
2. **驱动器（Drivers）**：用一条“表达式/曲线”让属性跟随另一属性自动变化（如轮子转动 = 前进距离）；
3. **约束（Constraints）**：让物体自动跟随/朝向/限制另一物体，如 跟踪约束（Track To）、路径约束（Follow Path）、复制变换（Copy Transforms）。

## 骨骼绑定（Rigging）

给角色或机械做“骨架”：

- 添加骨架物体（Armature），进入**编辑模式**画骨骼（Bone）；
- 在**姿态模式（Pose Mode）**摆姿势、插关键帧；
- 把网格绑定到骨架：选中网格再选骨架 → `Ctrl + P` → **自动权重（Automatic Weights）**；
- 自动权重不满意就进入**权重绘制**手动修正（见[雕刻与绘制](/docs/sculpt-paint)）。

进阶概念：**正向/反向动力学（FK/IK）**、**形态键（Shape Keys）**（做表情时逐顶点变形）、**约束叠加**组成的复杂控制链。Blender 有强大的**骨骼自定义形状**与**骨骼集合**，支撑角色师搭建专业绑定。

## 物理与模拟

Blender 内置多个物理系统，都在 **属性 → 物理（Physics）** 标签下：

| 系统 | 用在哪里 |
| --- | --- |
| **刚体（Rigid Body）** | 碰撞、堆叠、破碎（结合 Cell Fracture 插件） |
| **布料（Cloth）** | 旗帜、衣物随风/受力摆动 |
| **流体（Fluid）** | 液体模拟（域 + 流入物）；也支持烟雾/火焰 |
| **粒子（Particles）** | 毛发、群集、星空等（新版倾向用“头发曲线”系统替代发丝粒子） |
| **动态画笔（Dynamic Paint）** | 让物体“沾上”颜色或涟漪 |

> Blender 5.2 起，官方还在实验性地把物理系统**节点化**（基于节点的头发/布料模拟），意味着未来可以用几何节点般的可视化连线来搭建物理效果。

模拟基本流程：为物体添加物理类型 → 设定域/影响范围 → 烘焙（Bake）到缓存 → 播放验证。注意：模拟结果常依赖**帧率与比例**，场景单位（米/厘米）要先设对。
