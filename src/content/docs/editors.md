## 设计哲学：一切皆是编辑器

Blender 没有“弹出一堆浮动面板”的传统软件界面，而是把屏幕拆成若干个**区域（Area）**，每个区域承载一种**编辑器（Editor）**。编辑器负责显示与编辑某类数据，例如 3D 场景、图像、节点图、时间线或 Python 代码。

把鼠标放在区域角落拖动可以拆分屏幕；点区域左上角的图标即可更换编辑器类型。布局随**工作区**保存，每个工作区就是一套为特定任务排好的编辑器组合。

内置工作区包括：Layout（默认）、Modeling、Sculpting、UV Editing、Texture Paint、Shading、Animation、Rendering、Compositing、Geometry Nodes、Scripting 等——它们本质是“预设布局”，完全可改。

## 常用编辑器一览

### 核心编辑器

| 编辑器 | 用途 |
| --- | --- |
| **3D 视口（3D Viewport）** | 显示与操作三维场景，是使用最频繁的编辑器；左上角切换“物体/编辑/雕刻”等模式 |
| **大纲视图（Outliner）** | 以层级树查看场景中所有数据块与依赖关系 |
| **属性（Properties）** | 上下文相关的属性面板：活动物体的变换、修改器、材质、约束等 |
| **时间线（Timeline）** | 播放与定位关键帧，控制动画起止帧 |

### 数据与脚本编辑器

| 编辑器 | 用途 |
| --- | --- |
| **文本编辑器** | 编写与运行 Python 脚本、注释说明 |
| **Python 控制台** | 交互式执行 Python，适合调试 API |
| **信息（Info）** | 操作历史与运行日志（含 Python 命令回显） |
| **偏好设置（Preferences）** | 全局设置：语言、主题、快捷键、扩展管理（独立于工作区） |
| **文件浏览器（File Browser）** | 打开/保存文件、关联外部素材 |

### 图像与节点编辑器

| 编辑器 | 用途 |
| --- | --- |
| **图像编辑器（Image/UV）** | 查看与编辑图像、UV 布局；也用于查看渲染结果 |
| **UV 编辑器** | 展开并整理模型 UV，属于图像编辑器的一种模式 |
| **着色器编辑器（Shader）** | 用节点图编辑材质 |
| **合成器（Compositor）** | 用节点图做后期合成 |
| **几何节点编辑器** | 以节点图驱动几何体（程序化建模的核心） |

### 动画相关编辑器

| 编辑器 | 用途 |
| --- | --- |
| **曲线编辑器（Graph）** | 精细调整动画曲线与插值 |
| **摄影表（Dope Sheet）** | 总览与批量移动关键帧 |
| **非线性动画（NLA）** | 把动画片段像剪辑一样拼接 |
| **动作编辑器（Action）** | 管理命名动画片段（动作） |

### 视频与跟踪编辑器

| 编辑器 | 用途 |
| --- | --- |
| **视频序列编辑器（VSE）** | 非线性剪辑：拼接、转场、特效与音频 |
| **影片剪辑编辑器（Movie Clip）** | 摄像机/物体运动跟踪、遮罩与调色 |

## 理解“上下文相关”的界面

Blender 的一个反直觉之处在于**界面随选中对象变化**。属性编辑器显示什么，取决于当前激活的是物体、修改器、材质、灯光还是世界：

- 选择不同物体，属性编辑器顶部的标签（物体/修改器/材质…）会自动适配；
- 3D 视口左上角的“模式”决定了可用的工具——比如**编辑模式**下才能编辑顶点；
- 快捷键也随模式变化，例如 `Tab` 在物体模式与编辑模式之间切换，而在雕刻模式里则不然。

所以遇到“按钮不见了”，先检查：**我在哪个工作区？哪个模式？选中了什么？**——八成问题出在这三者之一。

## 学习提示

- 别试图背下所有编辑器，先熟悉 **3D 视口 + 属性 + 大纲视图** 这个黄金三角；
- 用 [快速上手](/docs/getting-started) 里的导航技巧在默认工作区里玩 10 分钟，胜过读一小时；
- 顶栏与区域右键菜单里藏着大部分切换入口。
