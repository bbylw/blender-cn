## 先选一个渲染引擎

渲染（Render）是把 3D 场景“拍成照片/影片”的过程。Blender 内置三个渲染引擎：

| 引擎 | 定位 | 特点 |
| --- | --- | --- |
| **EEVEE** | 实时渲染 | 基于光栅化 + 屏幕空间效果（5.2 中支持硬件光线追踪），秒级出图，适合交互预览、动画预览与风格化作品；在新版本中与 Cycles 的差异正在缩小 |
| **Cycles** | 物理正确渲染 | 路径追踪（Path Tracing），逐光线模拟真实光照；支持 CPU 与 NVIDIA / AMD / Intel GPU 加速；质量高，速度相对慢 |
| **Workbench** | 视口显示 | 只用于视口中的快速显示，一般不算最终渲染方案 |

引擎在**渲染属性（Render Properties）→ 渲染引擎**处切换。Cycles 与 EEVEE 各自有采样、降噪、光程等参数——追求速度开低采样 + 降噪，追求质量拉高采样。

## 场景里的“光”与“相机”

一个能渲染的场景最少要有：**物体 + 灯光 + 相机**（工作台除外）。

- **灯光类型**：点光（Point）、平行光/日光（Sun）、聚光（Spot）、面光（Area）——面光适合柔和影棚光；
- **世界（World）**：场景环境光与背景；可以用 HDR 环境贴图做真实感照明；
- **相机**：`Ctrl + Alt + 小键盘0` 把当前视图设为相机视角；相机属性里有景深、焦距等参数；
- **渲染输出**：`F12` 渲染当前帧，`Ctrl + F12` 渲染动画；结果可存 PNG / OpenEXR（带通道）/ FFmpeg 视频。

## 材质与着色器节点

在 **Shading 工作区**（着色器编辑器）里，用节点图把“材质”拼出来。最常用的是 **原理化 BSDF（Principled BSDF）** 节点——一个节点几乎能表达所有常见表面：金属、粗糙、清漆、次表面散射、发光……

材质思路（以真实感为目标）：

1. 颜色（Base Color）贴图给底色，粗糙度（Roughness）贴图控制高光；
2. 法线（Normal）贴图在不高模的情况下增加表面细节；
3. 用**着色器编辑器**查看实时结果，配合图像纹理节点连接外部贴图。

程序化纹理（噪波、渐变、Voronoi）可以免贴图生成木头、石头、云等效果。想深入学习，先搞懂“着色器节点 = 数据流 + 输入输出类型”这一点即可上手。

## 色彩管理：5.x 的重要变化

- Blender 5.0 起色彩管理管线全面升级，**原生支持宽色域与 HDR**，默认配置也随之变化（新增的标准输出配置让色彩更准确）；
- 渲染属性中可查看 **视图变换**（View Transform），它决定了画面“看起来”怎样（标准/对比度/AgX 风格色调映射等）；
- 输出 EXR 时可选择**线性或场景线性**工作流，把调色留给后期合成。

对普通用户：先不深究，直接渲染即可；等需要“画面更准/更一致”时再回头理解色彩空间（sRGB / Rec.709 / 线性）的概念。

## 合成：渲染只是开始

**合成器（Compositor）** 是节点化的后期工具，能对渲染结果继续处理：

- 渲染出**多通道（Render Passes）**（直接光、间接光、高光、Z 深度、物体 ID……），在合成器里重新组合与调色，甚至**换背景、加雾、做辉光（Glare）**；
- 合成结果可直接输出为最终帧/视频——很多作品其实是在这里“完成”的；
- 使用“合成”工作区，勾选“使用节点（Use Nodes）”开始搭建节点树。

## 输出设置小抄

- **帧范围**：在时间线设起始/结束帧；
- **分辨率与帧率**：输出属性里设（如 1920×1080、24 fps）；
- **输出目录与格式**：序列帧用 PNG/EXR，直接成片用 FFmpeg 视频（H.264/H.265，注意码率）；
- **渲染动画**：建议先渲 10 帧小样确认没问题，再整段渲染。
