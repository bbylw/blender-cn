## 核心概念

- **数据块（Data-Block）**：Blender 内部一切数据（网格、材质、动作、图像……）的最小单位，可被多处引用。见[资产、文件与数据系统](/docs/assets-files)。
- **场景（Scene）**：一个独立的“世界”，包含自己的物体、相机与时间线；一个 `.blend` 文件可含多个场景。
- **集合（Collection）**：组织物体的容器（旧称“图层”），可嵌套、可整体实例化。
- **物体（Object）**：场景里可见可操作的实体；物体只是“容器”，引用某份数据块（如网格）。
- **实例（Instance）**：多个物体共享同一份网格/集合数据的复用方式；改源数据，所有实例同步更新。
- **父级（Parent）**：建立层级关系，子物体跟随父物体变换；骨架与蒙皮网格的关系就是“父级-子级”的典型应用。

## 建模相关

- **网格（Mesh）**：由顶点（Vertex）、边（Edge）、面（Face）构成的建模对象，多变形建模的基础。
- **编辑模式（Edit Mode）**：在物体内部编辑顶点/边/面的模式，按 `Tab` 进入。
- **修改器（Modifier）**：叠加在物体上、可随时调整的“非破坏性”操作（细分、镜像、布尔等）。见[建模](/docs/modeling)。
- **非破坏性（Non-destructive）**：不直接改写原始数据、随时可撤销或改参数的流程（修改器、几何节点等）。
- **UV 展开（Unwrap）**：把三维表面摊平到二维平面，用于贴图定位。
- **法线（Normal）**：垂直于表面的方向向量，决定光照与“正反面”。
- **细分（Subdivision）**：把面细分成更多面；细分表面修改器可让低模变光滑。
- **拓扑（Topology）**：网格的顶点/边连接结构；布线质量影响形变与雕刻。

## 动画与绑定

- **关键帧（Keyframe）**：记录某属性在特定帧数值的标记点；两个关键帧之间由软件插值过渡。
- **插值 / 缓动（Interpolation / Easing）**：关键帧之间的过渡方式，决定动作的快慢节奏。
- **曲线编辑器（Graph Editor）**：把动画显示为曲线并精细调节的编辑器。
- **骨骼 / 骨架（Bone / Armature）**：驱动网格形变的层级结构；绑定（Rig）即建立骨骼对网格的控制。
- **姿态模式（Pose Mode）**：摆弄骨架姿势、为动画打关键帧的模式。
- **形态键（Shape Key）**：记录网格顶点在不同“形态”间的偏移，常用于表情动画。
- **驱动器（Driver）**：用表达式/曲线让某属性自动跟随其他属性变化。
- **约束（Constraint）**：让物体自动跟随/朝向/限制另一物体的规则。

## 雕刻与绘制

- **多精度（Multires）**：保留细分层级的雕刻修改器，可在不同细分级别间切换。
- **动态拓扑（Dyntopo）**：雕刻时按笔刷密度自动增加网格面数。
- **遮罩（Mask）**：锁定局部区域，让操作（雕刻、编辑）只作用于其余部分。
- **权重绘制（Weight Paint）**：以 0–1 数值绘制顶点影响权重，绑定骨骼时常见。
- **蜡笔（Grease Pencil）**：在 3D 空间绘制 2D 笔画的工具，用于 2D 动画与标注。

## 渲染与色彩

- **渲染引擎**：把 3D 场景计算成图像的模块。Blender 内置 EEVEE（实时）、Cycles（路径追踪）与 Workbench（视口）。
- **路径追踪（Path Tracing）**：Cycles 的算法——逐光线模拟光在场景中的弹射，物理正确但较慢。
- **着色器（Shader）**：定义表面如何响应光线的程序；Blender 用节点图组合着色器。
- **原理化 BSDF（Principled BSDF）**：一个覆盖金属、粗糙、透明等大多数材质需求的通用着色器节点。
- **采样（Samples）**：渲染时每个像素的光线计算次数；越多越干净、越慢，配合降噪可平衡。
- **宽色域 / HDR（Wide Gamut / HDR）**：能表示比传统 sRGB 更大颜色范围与更高动态亮度的色彩空间；Blender 5.0 起原生支持。
- **色彩空间（Color Space）**：颜色数值与可见颜色之间的映射约定，常见 sRGB、Rec.709、线性。
- **视图变换（View Transform）**：把渲染的线性数据“翻译”成显示器画面（标准/AgX 风格等）的环节。
- **合成（Compositing）**：用节点把渲染通道加工成最终画面的后期环节。
- **渲染通道（Render Pass）**：把光照拆成直接光、间接光、深度等多张图分别输出，供合成器重组。

## 界面与工作流

- **工作区（Workspace）**：为某类任务预设的界面布局集合。
- **区域（Area）**：屏幕上的一个矩形窗格，每种区域承载一种编辑器。
- **区块（Panel）**：属性等编辑器里可折叠的配置面板。
- **大纲视图（Outliner）**：以树状显示场景数据块层级与引用关系的编辑器。
- **游标（3D Cursor）**：3D 视口中的定位锚点（`Shift + 右键`放置），新建物体与变换中心的参考点。
- **LTS（Long Term Support）**：长期支持版本——只修 Bug 不加功能，维护期长达两年，适合生产环境。
